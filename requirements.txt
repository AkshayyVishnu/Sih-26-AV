# --- Planning fallback (Stage 5): PCLA-deployed agent, only if the ----
# --- classical Navigation Toolbox planner underperforms ---------------
# [EXTERNAL, not pip] PCLA — git clone github.com/MasoudJTehrani/PCLA
#   Apache-2.0. `python pcla_functions/download_weights.py` pulls any of
#   41 bundled checkpoints (TransFuser v3-v6/LEAD, PlanT/PlanT2, SimLingo,
#   ORION, CaRL, Roach, etc.). Default to the LIGHTEST/fastest bundled
#   agent for real-time margin (TransFuser v3/PlanT), not SimLingo/
#   LMDrive's heavier LLM-backed variants, unless a demo specifically
#   wants the flashier agent. NOTE: activating this fallback stacks TWO
#   layers of Python call overhead (your own py.* CARLA bridge + PCLA's
#   own per-step get_action() call) — budget latency accordingly.
#   Known bugs to test around before a demo: TransFuser route-deviation
#   on spawn (issue #9), PlanT non-finite-bbox crash (issue #11).
#   PlanT2 specifically (object-level, planning-only) is the structurally
#   closest match to a "planner node" — prefer it over end-to-end agents
#   (TransFuser v6/SimLingo/ORION) if the fallback is needed, since those
#   collapse perception+prediction+planning into one opaque model.
